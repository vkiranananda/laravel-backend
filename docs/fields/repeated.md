# Пример
```
'template' => [
    'type' => 'repeated',
    'name' => 'template',
    'label' => 'Шаблон формы',
    'prop-fields' => ['type'],
    'add-label' => 'Добавить поле',
    'style' => 'editor',
    'fields' => [
        'type' => [
            'name' => 'type',
            'type' => 'select',
            'label' => 'Тип',
            'hidden' => true,
            'options' => [
                 ['value' => 'text', 'label' => 'Текст'],
                 ['value' => 'image', 'label' => 'Картинка'],
            ]
        ],
        'text' => [
            'name' => 'text',
            'type' => 'textarea',
            'label' => 'Текст',
            'show' => [
                ['type' => '==', 'field' => 'type', 'value' => 'text'],
            ],
        ],
    ]
],
```
# Описание
Данный тип предназначен для того что бы выводить группу полей множество раз, например
добавлять какую то опцию к товару и делать состовные блочные страницы.
У группы полей есть свое меню, откуда можно вставить новую группу, переместить или удалить текущую.
Так же для удобства добавлена опция `prop-fields` которая позволяет добавить в это меню
часть полей из группы, например тип, что сделано в примере выше. Что бы не дублировать поле `type` 
два раза, к самому полю ставится опция `hidden`, которая позволяет скрыть его из основного списка
и доступ к нему будет только через меню.

# Опции
`prop-fields` - это массив названий полей которые надо вынести в меню группы полей. 
Меню обычно рисует
`fields` - тут перечисляем все поля которые будут в группе. Атрибут `show` для поля, может повлиять
на его видимость внутри группы. Например как в примере выше, поле `text` будет видно только если 
выбрана опция `Текст` в соседнем поле `type`.
`add-label` - текст кнопки добавить новый элемент. Не обязательно.
