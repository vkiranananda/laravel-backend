# Список чекбоксов

## Описание

Поле для выбора одного или нескольких значений из списка чекбоксов.

## Параметры

- `value` - значение по умолчанию
- `options` - массив опций, по умолчанию []. Каждый элемент массива это массив с ключами value и label.
- `unselected-value` - значение по умолчанию для невыбранного значения, по умолчанию '', для выбора только одного чекбокса. Для множественного выбора не используется.
- `yes-no` - использовать ли отображение значений чекбокса в виде "✅" или "❌", по умолчанию false.
  
# Пример

```php
  'checkbox-field' => [
    'name' => 'checkbox-field',
    'type' => 'checkbox',
    'label' => 'Список чекбоксов',
    'value' => 1,
    'unselected-value' => 0,
    'yes-no' => true,
    'options' => [
      [
        'value' => 1,
        'label' => 'Да',
      ]
    ],
  ],
```
