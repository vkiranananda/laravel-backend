# Выбор

**value** - значение по умолчанию
**col-classes** - классы для колонки
**options** - массив опций

# Пример

```php
  'select-field' => [
    'name' => 'select-field',
    'type' => 'select',
    'label' => 'Выпадающий список',
    'value' => 0,
    'col-classes' => 'col-6',
    'options' => [
      [
        'value' => 1,
        'label' => 'Да',
      ],
      [
        'value' => 0,
        'label' => 'Нет',
      ],
    ],
  ],
```
