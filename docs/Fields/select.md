# Выпадающий список

## Описание

Поле для выбора одного значения из списка.

## Параметры

- `value` - значение по умолчанию
- `options` - массив опций, по умолчанию []

# Пример

```php
  'select-field' => [
    'name' => 'select-field',
    'type' => 'select',
    'label' => 'Выпадающий список',
    'value' => 0,
    'options' => [
      [
        'value' => 1,
        'label' => 'Да',
      ],
      [
        'value' => 0,
        'label' => 'Нет',
      ],
    ],
  ],
```
