# Информация

## Общие параметры для всех типов

- `name` - имя поля, обязательное поле, оно же ключ в массиве данных. Если сохраняете в базу, то оно должно быть корректным.
- `type` - тип поля, обязательное поле, данное поле смотрите к описанию нужного поля.
- `col-classes` - классы для колонки, по умолчанию ''
- `label` - текст для лейбла, по умолчанию ''
- `show` - массив условий для отображения поля (см. ниже)

## Скрытие поля опция `show`

Отоборажаемые или скрытые поля привязываются по полю `select`. В опции `show` нужно указать условия для отображения поля.

### Описание условий

- `type` - тип сравнения (==, !=)
- `field` - имя поля для сравнения
- `value` - значение для поля сравнения 
- `operator` - оператор сравнения (||, &&), используется если несколько условий, если условие одно, то оператор не нужен

### Пример

```php
'show' => [ 
    [ 'type' => '==', 'field' => 'template', 'value' => '' ],
    [ 'operator' => '||', 'type' => '==', 'field' => 'template', 'value' => 'contacts' ]
]	
```
