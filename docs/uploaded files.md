# Хелпер для работы с файлами UploadedFiles

## Производительность.

Данные функции подготавлвают массив ID изображений для того что бы получить все изображения из массива данных одним запросом. Оптимизация запросов.

### loadByList

Загружает изображения из массива данных, передается список записей и id поля с изображением. Данная фунция нужна что бы получить все изображения из массива данных одним запросом.

```php
UploadedFiles::loadByList($list, $field);
```

### loadByField

Загружает изображения из конкретной записи, передается запись и id или массив id полей с изображением. Данная фунция нужна что бы получить все изображения из конкретной записи одним запросом.

```php
UploadedFiles::loadByField($post, $field);
```

### loadByPost

Загружает все изображения из конкретной записи, передается запись. Данная фунция нужна что бы получить все изображения из конкретной записи одним запросом.

```php
UploadedFiles::loadByPost($post);
```

## Получение данных

### getByField - Инитим данные из поля, для выборки массива

Первый параметр запись, второй название поля в записи, а третий означает получить только первый элемент - true или все элементы - false. Если first = true, выведется только конкретный элемент, иначе вывод будет как массив элементов.

```php
UploadedFiles::getByField($post, $field, $first = false);
```

### thumbUrl - Выводит URL миниатюры или оригинального файла. Только для картинок. Если $original = true, то будет выведен массив с оригинальным и миниатюрой файла иначе будет выведен только URL **миниатюры**.
пример: [100, 100, 'fit'], [100, 'auto']

```php
UploadedFiles::thumbUrl($size);
```

### url - Выводит URL файла.
пример: [100, 100, 'fit'], [100, 'auto']

```php
UploadedFiles::url($size);
```
